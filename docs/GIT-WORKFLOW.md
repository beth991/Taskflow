# TaskFlow Git Workflow

- Develop on the `main` branch unless the user directs otherwise.
- Keep work separated by milestone and use Conventional Commit messages, such as `feat: implement user authentication`.
- Complete and test a milestone before proposing its commit.
- Review `git diff` and `git status` and verify that `.env` and credentials are not included.
- Ask the user before every commit. Do not make empty commits or commit incomplete milestones.
- Push only after the user explicitly approves the push.
